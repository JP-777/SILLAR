Sistema Integrado y Licenciable de Logística, Administración y Retail

Sistema de diseño del producto: panel de administración, instalador y material de venta. La web pública de cada cliente usa su propio tema y no se parece a esto. Todo lo que ves aquí se define con variables CSS: cambiar de marca es cambiar un bloque de tokens, nunca un componente.
